# Artfolio
A personal project for showcasing art through a virtual exhibition and management system.

**[View the Live Website](https://artfolio-e0izzt9f3-krishna28004s-projects.vercel.app/)**

## Overview
This project is an art portfolio that combines a 3D gallery with a backend system for managing commissions and visualizing art in real-world spaces. The goal was to build a functional, stable platform for artists to present and sell their work.

## Main Features
*   **3D Exhibition:** A virtual gallery built with Three.js/React Three Fiber. It uses optimized rendering to display pencil sketches in an interactive environment.
*   **Commission System:** A form-based system for users to request custom artwork. It includes image uploads, database storage, and email notifications.
*   **WallFit Engine:** A simple tool to help users visualize how an artwork would appear on their own walls using a photo upload.
*   **Secure Checkout:** Integrated payment processing for artwork acquisitions.

## Tech Stack
*   **Framework:** Next.js (TypeScript) & Tailwind CSS
*   **3D Engine:** Three.js (R3F)
*   **Database & Auth:** Supabase
*   **Media Storage:** Cloudinary
*   **Notifications:** Resend
*   **Payments:** Razorpay
